# Contributing

## Getting Started

1. Clone the repository
2. Run `cp .env.example .env` and fill in your credentials
3. Run `npm install`
4. Validate your environment: `npm run validate:env`
5. Run tests: `npm test`

## Before Submitting a PR

- Run `npm run lint` and fix any issues
- Run `npm test` and ensure all tests pass
- Validate environment configuration is correct
- Update documentation for any new features

## Code Style

We use ESLint and Prettier. Run `npm run lint` before committing.
